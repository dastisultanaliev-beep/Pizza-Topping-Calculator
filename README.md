# Pizza Topping Calculator 🍕

A simple pizza topping calculator built with Python and CustomTkinter.

## Features

- Select pizza toppings using checkboxes.
- Calculate the total price automatically.
- Dark mode interface.
- Simple and user-friendly design.

## Available Toppings

| Topping | Extra Price |
|---|---:|
| Cheese | 80 KGS |
| Mushrooms | 60 KGS |
| Jalapenos | 50 KGS |
| Macadamia Nuts | 1000 KGS |

**Base pizza price:** 400 KGS

## Requirements

- Python 3.10 or newer
- CustomTkinter

## Installation

Install the required library:

```bash
pip install customtkinter
```

## How to Run

1. Download or clone this repository.
2. Open a terminal in the project folder.
3. Run the application:

```bash
python main.py
```
